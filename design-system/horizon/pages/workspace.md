# Lesson workspace

The workspace is an operating surface, not a product landing page. Put the lesson title and source status with the player. Keep playback time visible beside the question's evidence boundary. Present the server-returned eligible block count as a separate fact, then show the assistant's answer or refusal with inspectable source and location.

On desktop, use the current two-column lesson layout: player, scope and transcript on the left; assistant on the right. On mobile, preserve reading order: player, scope, assistant, transcript. Keep the player controls attached to the video panel. Do not overlay controls on lecture content.

Answers use an opaque reading surface. Citation quotes use a subtle one-pixel neutral border. Source kind and timestamp remain visible before expansion; available seek and transcript actions remain ordinary keyboard-operable buttons.

The question textarea is programmatically described by its current scope label (“through mm:ss”). When scope changes, the description changes with it. Distinguish “not enough evidence” from unavailable providers or data. Keep synthetic course messaging visible when that corpus is selected.

Avoid a second dashboard or marketing hero inside this route. The first task is to watch, ask at the current position, and inspect the evidence.
